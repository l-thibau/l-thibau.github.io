# Foto de perfil

Para testar uma nova foto localmente, substitua apenas o arquivo `profile.jpg` nesta pasta.

- Mantenha o mesmo nome: `profile.jpg`
- Use JPG ou converta a imagem para JPG antes de substituir.
- Não é necessário editar `index.html`.
- O site recorta a imagem em círculo usando CSS. Para ajustar a posição do recorte, edite `object-position` na regra `.portrait` de `styles.css`.
