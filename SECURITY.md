# Security Policy

## Scope

This repository contains a static academic website. It has no server-side application, database, form handler, analytics tracker, or client-side API integration.

## Reporting a vulnerability

Please report potential security issues privately to `leonardo_thibau@hotmail.com`. Do not include credentials, tokens, or personal data in a public issue.

## Security controls in the site

- dependency-free HTML and CSS;
- restrictive Content Security Policy declared in the page;
- no remote scripts, trackers, forms, or API requests;
- external links use `rel="noopener"`.

GitHub account protection, MFA, repository access control, branch settings, Pages settings, and domain/DNS configuration remain account-level responsibilities.
